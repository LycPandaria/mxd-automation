## 1. 每帧决策主流程 `decide()`

```
每帧入口 decide(ctx)
│
├─ fsm.tick()                                  # 帧计数 +1
├─ 更新定位/卡住统计:
│    self_position 存在 → 复位 self_pos_stale；比对 _last_self_pos 累计 _stuck_counter
│    self_position 为空 → self_pos_stale_frames += 1
│
├─ 【优先级1 加血】 hp_ratio < hp_threshold 且 < 0.95 ?
│     是 → FSM=HEALING → 释放移动 → press_key(hp_key, 冷却1.5s) → return
│
├─ 【优先级2 加蓝】 mp_ratio < mp_threshold 且 < 0.95 ?
│     是 → FSM=RECOVERING → 释放移动 → press_key(mp_key, 冷却1.5s) → return
│
├─ 【优先级3】 ctx.monsters 有怪 ?
│     是 ─────────────────────────────▶ _handle_monsters(ctx)   （见 §2）
│
└─ 否（画面无怪）:
       ├─ 若 FSM==ATTACKING 且 _target_monster 仍锁着:
       │     遮挡判定 _occluded_target() ?
       │       成立 → 短手走 _handle_melee / 长手走 _attack（虚拟目标继续打）→ return
       │       不成立 ↓
       ├─ FSM=IDLE；清空 _target_monster / _attack_stale_counter
       └─ _explore(ctx)                                        （见 §5，不改 FSM 状态）
```

## 2. 怪物处理子流程 `_handle_monsters()`（长手）

```
_handle_monsters(ctx)
│
├─ target = _resolve_locked_target(ctx)
│    优先沿用 _target_monster（同一只怪仍可见且仍同平台）
│    不在画面 → 遮挡判定；否则 _pick_best_target（同平台·水平最近）
│
├─ target 为 None ?
│    是 且 ATTACKING 且有旧锁定 → 沿用旧锁定（容忍单帧漏检）
│    否则 → 清锁定 → FSM=IDLE → _explore → return
│
├─ 残影防护: 同一目标(_is_same_monster)持续 ATTACKING 累计 _attack_stale_counter
│    ≥ 90 帧 → 排除该目标重新 _pick_best_target；仍无 → IDLE + _explore
│
├─ attack_type == "short" ? ──是──▶ _handle_melee(ctx, target)   （见 §3）
│
├─ foot = _effective_self_pos(ctx)
│    （定位失败但站定攻击中且 ≤60帧时效 → 用 _last_self_pos 兜底）
│    foot 为 None → 清锁定 → FSM=IDLE → _explore → return
│
├─ monster_foot = (mx, target.y + target.h)          # 怪脚底
├─ （estimate_path_distance 仅写日志，不影响分支）
│
└─ 同平台?  _same_platform(py, monster_foot_y)  = |脚底y差| ≤ attack_range_y
     ├─ 是:
     │    _can_attack() ?  （同平台 + 水平≤attack_range，或攻击中滞回 +60px/+40px）
     │      是 → FSM=ATTACKING → _attack(ctx, target)
     │      否 → FSM=CHASING  → _chase(ctx, target)
     └─ 否 → 清锁定 → FSM=IDLE → _explore      ★ 不爬绳、不跳跃、不跨层追
```

## 3. 短手近战子流程 `_handle_melee()`

```
_handle_melee(ctx, target)          # attack_type == "short"
│
├─ foot = _effective_self_pos(ctx)
│    （None 且站定攻击中、最后位置仍在贴脸范围 → 用最后位置兜底；否则释放移动 return）
├─ dy = |sy - 怪脚底|  > attack_range_y ? → 清锁定 → IDLE → _explore
├─ dx = |sx - 怪近侧身体边缘|       # _melee_edge_x，怪半宽封顶50px
├─ 命中区 = 50(MELEE_RANGE) + 10(命中容差) = 60px
│
└─ dx > 60 ?
     ├─ 是 且 ATTACKING 且 dx ≤ 90(50+40滞回窗口):
     │     _melee_leave_frames += 1；< 6帧 → 原地继续 _melee_attack
     │     累计 ≥6帧 → FSM=CHASING → _melee_chase
     ├─ 是（其它情况）→ FSM=CHASING → _melee_chase
     └─ 否 → 清零防抖 → FSM=ATTACKING → _melee_attack
```

## 4. 状态转移图（真实生效的 5 个状态）

`CLIMBING`、`DROPPING` 两个枚举值**从未被 transition 进入**，实际运行只用到 5 个状态：

```
                    ┌──────────────┐
         ┌─────────▶│     IDLE     │◀──────────────┐
         │          │  (探索/待命)  │               │
         │          └──────┬───────┘               │
         │   同平台有怪     │ 同平台有怪(已够近)     │ 怪消失/残影/跨层/定位失败
         │                 ▼                       │
         │          ┌──────────────┐               │
         │          │   CHASING    │──── 进入攻击范围 ──▶┐
         │          │ (追击/移动)   │                  │
         │          └──────┬───────┘                  │
         │    怪走远/防抖超限│                          ▼
         │                 │                  ┌──────────────┐
         │                 └─────────────────▶│  ATTACKING   │
         │                                    │ (站定攻击)    │
         │                                    └──────────────┘
         │
         ▼  (任意状态)
   ┌──────────────┐     ┌──────────────┐
   │   HEALING    │     │  RECOVERING  │      ★ 瞬态：按完键下一帧被正常转移覆盖，
   │  (加血中)     │     │  (加蓝中)     │        没有"血满→回之前状态"的显式逻辑
   └──────────────┘     └──────────────┘
```

### 转移条件表（仅真实发生的边）

| 源 → 目标 | 触发条件 |
|-----------|----------|
| 任意 → HEALING | `hp_ratio < hp_threshold` 且 `<0.95` |
| 任意 → RECOVERING | `mp_ratio < mp_threshold` 且 `<0.95` |
| IDLE → CHASING | 同平台有怪，水平距离 > 攻击范围 |
| IDLE → ATTACKING | 同平台有怪，水平距离 ≤ 攻击范围 |
| CHASING → ATTACKING | 追击进入攻击范围 |
| ATTACKING → CHASING | 怪走远 / 短手防抖帧数超限 / 目标切换 |
| ATTACKING / CHASING → IDLE | 怪消失、残影超时、跨层、自身定位失败 |

## 5. 动作原语汇总（决策层输出）

| 原语 | 内部方法 | 触发输出 |
|------|----------|----------|
| 站定攻击(长手) | `_attack` | `key_up(移动键)` + 转向(`press_key(left/right)`) + `_cast_skill` |
| 站定攻击(短手) | `_melee_attack` | 同上，转向带 0.6s 冷却、25px 重叠死区 |
| 追击(长手) | `_chase` | `_hold_move(left/right)`；卡住→`press_key(jump_key)` |
| 追击(短手) | `_melee_chase` | `_hold_move(left/right)`；`stop_at=max(5,50)` |
| 技能释放 | `_cast_skill` | 轮转 `skills` → `press_key(key, cooldown)` |
| 探索 | `_explore` | `_hold_move(方向)`；无地板→跳；卡住→跳+反向；180帧换向 |
| 加血/加蓝 | `decide` 内联 | `key_up(移动键)` + `press_key(hp/mp_key, 1.5s)` |

## 6. 三个容易误读的点

1. **HEALING/RECOVERING 是"瞬态标记"**：`decide()` 按完药键就 `return`，FSM 停留在该状态，直到下一帧被 `IDLE/CHASING/ATTACKING` 覆盖。`fsm.py` 里的 `previous` 字段**没有**被用来"血满回上一状态"。
2. **探索不改 FSM 状态**：`_explore()` 期间 FSM 一直停在 `IDLE`，探索行为由独立的 `_explore_direction / _explore_frame_count / _stuck_counter` 驱动，与状态机解耦。
3. **跨层怪物 = 直接放弃**：`_handle_monsters` 中不同平台就清空锁定转探索，所谓"攀爬/跳跃追击"在当前代码里**不生效**（对应方法为死代码）。
